# Histórico de versões / Version history

Os formulários seguem a numeração MAJOR.MINOR.PATCH (versionamento semântico):

- **MAJOR** (2.0.0): mudança que altera o protocolo ou torna incompatíveis os registos guardados (campos retirados, fases reorganizadas).
- **MINOR** (1.1.0): campos, opções, línguas ou funções novas, sem perder os registos guardados.
- **PATCH** (1.0.1): correções de texto, tradução ou erros, sem mudar a estrutura.

A versão aparece no rodapé da página, nos ficheiros exportados (JSON, Word, Markdown) e na declaração gerada. Os registos devem indicar a versão com que foram preenchidos.

*The forms follow MAJOR.MINOR.PATCH numbering. MAJOR: changes to the protocol or to saved-record compatibility. MINOR: new fields, options, languages or features. PATCH: wording, translation or bug fixes.*

## 1.0.0 (2026-11-23): versão de referência / reference version

Primeira versão estável, a usar como base para as seguintes. Reúne as versões de desenvolvimento abaixo.

- Seis fases (Reporting, Relating, Responding, Reasoning, Reconciling, Reconstructing) para texto, imagem e vídeo.
- Cinco línguas: português, inglês, espanhol, italiano e coreano.
- Ajudas e exemplos em cada campo; estado das fases; nota de alcance na Fase 6.
- Declaração de uso que se atualiza com as respostas.
- Exportação para JSON, Word, Markdown e PDF; junção de dois registos (JSON).
