# AI Curatorial Protocol (AICP)

**AI 생성 콘텐츠 큐레이션 양식: 텍스트, 이미지, 영상**

생성형 AI로 만든 모든 콘텐츠, 즉 텍스트(논문, 학업 과제, 보고서, 교육 자료, 대중용 글), 이미지, 영상에 첨부하는 단계별 간단 양식 6종입니다. 먼저 콘텐츠 유형을 선택하면 항목이 그에 맞게 바뀝니다. 각 항목에는 도움말과, 필요한 경우 예시가 있습니다. 5R 모델(Bain et al., 2002)에 새로운 단계인 Reconciling을 더해 확장한 것입니다(Costa et al., 2026).

## 사용 방법

1. 먼저 콘텐츠 유형(텍스트, 이미지, 영상, 혼합)을 선택하십시오. 그다음 1단계부터 6단계까지 순서대로 작성합니다. 새로운 정보가 생기면 이전 단계로 돌아갈 수 있으며, 돌아간 사실을 기록하십시오.
2. 도움말과 예시는 참고용입니다. 예시는 가상의 사례(간호사 번아웃에 관한 콘텐츠)입니다.
3. "예"와 "아니요"는 실제로 한 일을 기록하는 것이며 옳고 그름을 뜻하지 않습니다. 모르는 경우 "모름"이라고 쓰십시오. 그것도 유효한 답입니다.
4. 생성된 원본(텍스트, 이미지, 영상)을 보관하고 이 양식을 최종본에 첨부하십시오. 항목에 개인정보를 쓰지 마십시오.
5. 결정과 최종 콘텐츠에 대한 책임은 언제나 서명하는 사람에게 있으며, AI에게 있지 않습니다.

## 1단계 · Reporting: 콘텐츠의 출처 기록 (Provenance Record)

_이 콘텐츠는 어떻게 만들어졌습니까? AI가 어떻게 생성했는지 아는 내용을 기록하십시오._

콘텐츠 / 기록 코드: ____  큐레이터: ____  날짜: ____

### 콘텐츠의 출처

**1. 도구와 버전** _도구 이름과, 표시되어 있다면 버전 또는 모델(보통 화면이나 설정에서 확인 가능). 웹 검색 기능이 켜져 있었는지도 적으십시오._ _예: ChatGPT, 화면에 표시된 모델, 웹 검색 꺼짐_

> 

**2. 날짜와 시간** _결과는 날짜와 버전에 따라 달라질 수 있으므로 기록이 중요합니다._ _예: 2026-10-12, 15시_

> 

**3. 요청 내용(프롬프트)** _처음 요청과, 이후 내용·자료·방향을 바꾼 지시를 작성한 그대로 기록하십시오. 대화 전체를 복사할 필요는 없으며, 전체 기록이 보관된 위치를 적으십시오. 여러 번 시도했다면 몇 번이었고 어느 것을 사용했는지 적으십시오._ _예: "포르투갈 간호사의 번아웃에 관해 참고문헌을 포함한 한 단락을 써 줘." / "근무를 마치고 지친 간호사의 수채화풍 삽화."_

> 

**4. 어느 부분을 AI가 생성했습니까?** _"변형": 원본(텍스트, 이미지, 영상)은 본인의 것이고 AI가 수정하거나 개선한 경우입니다. "일부"를 선택하면 어느 부분인지 적으십시오._: ☐ 전부  ☐ 일부  ☐ 본인 자료의 변형  ☐ 모름  ____

**5. AI에 문서, 이미지 또는 기타 자료를 제공했습니까?** _파일을 첨부했거나, 텍스트를 붙여 넣었거나, 참고 이미지를 주었다면 "예"입니다. 자료 없이 참고문헌을 요청했다면 AI가 지어냈을 수 있습니다. 다른 사람의 이미지를 사용했다면 권리 문제에 유의하십시오._: ☐ 아니요  ☐ 예  ____

**6. 개인정보나 기밀 정보를 사용했습니까?** _예: 연구 참여자 이름, 면담 자료, 미발표 원고, 실제 인물의 사진이나 목소리. "예"라면 어떻게 보호했는지 적으십시오._: ☐ 아니요  ☐ 예  ____

**7. 원본은 어디에 보관했습니까?** _생성된 원본을 편집하지 않은 상태로 항상 보관하십시오(파일 또는 링크)._ _예: 폴더 AICP-001/original_

> 

**8. 알 수 없는 것은 무엇입니까?** _모르는 것을 밝히는 것도 엄밀성의 일부입니다._ _예: AI가 어떤 텍스트나 이미지로 학습했는지; 어떤 자료를 사용했는지_

> 

### [이미지·영상만] 이미지와 영상

**9. 생성 설정** _화면 비율, 해상도, 스타일, 네거티브 프롬프트, 시드(도구가 보여 주는 경우)._ _예: 16:9, 수채화풍, 이미지 안 글자 없음_

> 

**10. 이것을 고르기까지 몇 번 생성했습니까?** _여러 결과 중 하나를 고른 것도 본인의 결정이므로 기록하십시오._ _예: 이미지 8장 중 5번째 선택_

> 

**11. 워터마크나 콘텐츠 자격 증명이 있습니까?** _일부 도구는 파일이 AI로 생성되었음을 눈에 보이는 표시나 메타데이터(예: Content Credentials)로 남깁니다. 이를 제거하지 마십시오._: ☐ 예, 눈에 보임  ☐ 예, 메타데이터에 있음  ☐ 아니요  ☐ 모름

**[영상만] 12. 길이, 음성, 음악** _영상 길이. 음성과 음악은 AI가 생성했습니까, 직접 녹음했습니까, 아니면 라이브러리에서 가져왔습니까? 어떤 라이선스입니까?_ _예: 2분; AI 생성 음성; 무료 음원 라이브러리 음악(CC BY)_

## 2단계 · Relating: 신뢰할 수 있는 자료와 비교 (Cultural Anchoring)

_내가 아는 자료는 무엇을 말합니까? 콘텐츠를 해당 주제의 신뢰할 수 있는 자료와 비교하십시오._

콘텐츠 / 기록 코드: ____  큐레이터: ____  날짜: ____

### A. 비교 자료(신뢰할 수 있는 자료 2~3개 선택)

> 콘텐츠에 출처가 없다면(예: 교육 자료나 이미지), 교재, 교육과정, 공식 문서, 실제 사진이나 이미지 같은 주제별 기준 자료와 비교하십시오.

| --- | --- |
| _예: 해당 분야 대표 교재; 최근 논문; 병동 사진_ | _예: 도서관, Scopus, SciELO, Google Scholar, 사진 아카이브_ |

|   |   |

### [텍스트만] B. 참고문헌과 주장 확인(가장 중요한 것부터)

> 제목과 DOI로 문헌을 검색하십시오. "텍스트의 주장과 일치하는가?"에는 자료가 주장을 뒷받침하는지, 부분적으로 뒷받침하는지, 반박하는지 표시하고, 확인하지 못했다면 이유를 적으십시오. "확인한 곳"에는 참고한 쪽이나 절과, 찾은 대응 관계를 한 문장으로 적으십시오. 텍스트를 사용하기 전에 모든 참고문헌을 확인해야 합니다(6단계).

| 텍스트의 주장 또는 참고문헌 | 실재하는가? | 텍스트의 주장과 일치하는가? | 확인한 곳(쪽 또는 절) |
| --- | --- | --- | --- |
| _예: (Ferreira & Almeida, 2021)_ |   |   | _예: Google Scholar와 DOI_ |

### C. 종합

**자료와 일치하는 것은 무엇입니까?** _자료로 확인된 콘텐츠의 생각이나 요소._

> 

**빠진 중요한 관점은 무엇입니까?** _충분히 다루어지지 않은 중요한 관점(저자, 언어, 국가, 집단, 접근)을 적고, 그 부재가 왜 콘텐츠를 제한하는지 설명하십시오._ _예: 포르투갈어 연구; 남성 또는 나이 든 간호사_

> 

**최신이며 내 맥락에 적합합니까?** _자료가 있다면 출판 연도(보통 최근 5~10년, 고전 제외)를 확인하고, 내 학문 분야와 대상, 국가에 맞는지 보십시오._: ☐ 예  ☐ 부분적으로  ☐ 아니요  ☐ 평가 안 함

## 3단계 · Responding: 시험하고 경고 신호 찾기 (Bias and Diversity Audit)

_무엇을 관찰하고 어떻게 반응합니까? 문제를 찾고, 요청을 바꾸면 어떻게 되는지 보십시오._

콘텐츠 / 기록 코드: ____  큐레이터: ____  날짜: ____

### A. 첫 반응

**무엇이 놀랍거나, 불편하거나, 설득력 있습니까?** _분석하기 전에 즉각적인 반응을 적으십시오._ _예: 수치가 있어 설득력 있었지만 출처를 모르겠다. / 이미지는 보기 좋지만 간호사가 모두 젊다._

> 

### B. 시험: 요청 바꾸기(한 가지만 바꿔 AI에 다시 요청)

> 국가, 이론, 언어, 등장인물을 바꾸거나 반대 의견을 요청해 볼 수 있습니다. 응답이 달라지는 것 자체는 문제가 아니며, 맥락이 바뀌었다면 당연할 수 있습니다. 모순, 근거 없는 주장, 도구가 설명하지 못하는 차이가 생겼는지 기록하십시오.

| 요청에서 바꾼 것 | 응답에서 달라진 것 |
| --- | --- |
| _예: 반론을 요청함; 다양한 연령의 간호사를 요청함_ | _예: 텍스트가 한계를 인정하기 시작함_ |
|   |   |

### [텍스트만] C. 텍스트의 경고 신호

> "위치"에는 경고 신호를 보여 주는 구절과 그 위치를 적고, 왜 문제라고 보는지 한 문장으로 설명하십시오. 예: "결론: ‘이 접근은 더 나은 학습을 보장한다’. 지나친 확신: 이를 보장할 결과가 제시되지 않음."

| 경고 신호 | 응답 | 위치(발췌) |
| --- | --- | --- |
| **지나친 일반화**: 근거 없이 "모두", "항상", "유럽 전역" 같은 표현을 씀. | ☐ 있음 ☐ 없음 ☐ 평가 안 함 |   |
| **지나친 확신**: 뒷받침하는 자료 없이 "증명한다", "없앤다", "입증한다"고 말함. | ☐ 있음 ☐ 없음 ☐ 평가 안 함 |   |
| **항상 동의함**: 반대를 요청해도 동의합니까? AI는 사용자에게 맞추려는 경향이 있음. | ☐ 있음 ☐ 없음 ☐ 평가 안 함 |   |
| **일부 목소리 배제**: 한 나라, 한 언어, 한 학파의 저자나 사례만 등장함. | ☐ 있음 ☐ 없음 ☐ 평가 안 함 |   |

## 6단계 · Reconstructing: 결정하고 기록하기 (Documented Curatorial Decision)

_무엇을 결정합니까? 이전 단계에 근거하고, 사람이 책임지며, 글로 남기는 결정입니다._

콘텐츠 / 기록 코드: ____  큐레이터: ____  날짜: ____

### A. 결정

> AICP의 결론은 수행한 큐레이션 과정을 기록한 것입니다. 그 자체로 콘텐츠에 제시된 도구, 결과, 모델의 과학적 타당성을 입증하지는 않습니다.

**하나를 선택하십시오**

- ☐ **사용**: 그대로 사용; 어느 단계에서도 문제가 없을 때만
- ☐ **맥락 설명과 함께 사용**: 출처(AI)와 한계를 설명하는 메모와 함께 사용
- ☐ **수정 후 사용**: 일부를 살리고 나머지는 다시 만들거나 고침
- ☐ **사용하지 않음**: 사용하지 않음; 이유를 기록

**이유는 무엇입니까?** _1~5단계의 근거를 2~3문장으로 적으십시오. "수정 후 사용"을 골랐다면 무엇을 바꾸는지 적으십시오._ _예: 실재하지 않는 참고문헌과 지나친 확신이 있으며, 검토에서 확인됨._

> 

### B. 사용 전 확인 사항

**[텍스트만] 텍스트: 완료한 항목에 표시**: ☐ 참고문헌을 원문에서 확인함(있는 경우)  ☐ 데이터와 사실을 확인함  ☐ 서명자가 텍스트를 다시 쓰고 책임짐  ☐ 저작권과 개인정보 문제를 처리함  ☐ 전체 텍스트를 최종 검토함

**[이미지·영상만] 이미지나 영상: 완료한 항목에 표시**: ☐ "AI 생성" 표시를 눈에 보이게 함  ☐ 워터마크와 출처 메타데이터를 보존함  ☐ 표현된 요소를 확인함  ☐ 권리와 동의 문제를 처리함(인물, 화풍, 브랜드, 음악)  ☐ 대체 텍스트나 자막을 넣음
